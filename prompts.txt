2026-11-19T13:22:00-05:00  MODE CHOICE: PTC
Chose PTC (Programmatic Tool Calling) over Standard, Minimal and Creator.
Why: PTC keeps every Standard capability but batches tool calls into one
TypeScript program, which fits this build - scaffold a dozen dbt files, read a
schema, run dbt build, all in a few programs instead of dozens of round trips.
Intermediate tool output stays out of context. Minimal drops web search and
subagents; Creator is for DSH plugins, not data work.
Caveat: PTC does not roll back a program that fails half way, so the build is
verified with dbt build after each batch rather than at the end.
